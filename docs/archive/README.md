# Archived development notes

The files in this folder are **historical development notes** from the
project's build-out (May–June 2026): session logs, handoff summaries,
build plans, and internal code/GUI audits.

They are **superseded** by the top-level [README.md](../../README.md)
(current status, usage, limitations) and [CHANGELOG.md](../../CHANGELOG.md)
(dated change history). They are kept only for provenance, so that the
reasoning behind design decisions stays traceable.

Treat everything here as a snapshot of its date, not as current
documentation. In particular:

- Test counts, device counts, "known issues" and pipeline descriptions
  reflect the state at the time each note was written.
- References to `GOALS.md` point to a private working goal list that is
  not part of the public repository. The forward-looking plan now lives
  in [LEARNED_SEGMENTATION_ROADMAP.md](../LEARNED_SEGMENTATION_ROADMAP.md).
- Paths such as `results/...` refer to the local, git-ignored output
  folder; those files are not distributed.
